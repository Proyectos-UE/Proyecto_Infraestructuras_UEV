## Descripción del proyecto

TrendWatch es un proyecto que busca detectar tendencias de mercado a partir de datos obtenidos de distintas fuentes. Para ello, desarrollaremos una herramienta que permita recopilar y almacenar información, analizar su evolución e identificar aumentos de interés en determinados productos. Los resultados se podrán consultar a través de una API y visualizar en un panel interactivo.

El proyecto también nos permitirá poner en práctica los conocimientos de infraestructuras, servicios web, bases de datos y despliegue con Docker.
